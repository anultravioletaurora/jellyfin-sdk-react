# @jellyfin/sdk-react

An SDK for performing Jellyfin operations in a React Native app.

> [!WARNING]
> This package is in early development (`0.0.x`). APIs may change without notice.

## Installation

```sh
npm install @jellyfin/sdk-react
```

This library is a [Turbo Module](https://reactnative.dev/docs/turbo-native-modules-introduction) and requires the React Native New Architecture.

## Usage

```js
import { multiply } from '@jellyfin/sdk-react';

const result = multiply(3, 7);
```
